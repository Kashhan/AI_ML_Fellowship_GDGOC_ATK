# Task 4 Libraries Packaging and Production Readiness

## Objective
This task focuses on converting previously written Python scripts into reusable modules,
organizing code in a clean structure, and preparing the project for production readiness.
All logic used in this task comes from earlier tasks and is refactored without changing behavior.

## Requirements
Python version 3 or above must be installed on the system.

No external libraries are required to run this task.

## Folder Structure
The Task4 folder is organized as follows.

modules contains refactored code from Task 1 Task 2 and Task 3  
mypackage contains a custom Python package  
main.py is the entry point for evaluation  
README.md contains execution and explanation  
requirements.txt lists dependencies  

## Modules Overview
math_ops handles area of circle and factorial logic  
string_ops handles string reverse logic  
games contains the number guessing game  
records contains student records and contact manager  
bank contains the bank account system  
generators_mod contains generator functions  
decorators_mod contains execution time decorator  

All modules are import safe and do not execute automatically.

## How to Run for Evaluation

Step 1  
Open terminal or command prompt

Step 2  
Navigate to the Task4 directory

Step 3
Run the main file

python main.py

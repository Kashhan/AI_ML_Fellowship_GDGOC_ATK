# Student Management App

This is a simple Student Management Application built using Python and Streamlit.  
The project allows users to add student records and view them through a web interface.  
Student data is stored locally using file handling.

This project is created as part of Week 1 Task 5 Mini End to End Python Project.

## Features

- Add new student records
- View all saved student records
- Data persistence using JSON file
- Object Oriented Programming
- Error handling for missing or invalid data
- Simple and clean Streamlit user interface

mini_project/

## Technologies Used

- Python
- Streamlit
- JSON for data storage

## How to Run the Project

1. Clone the repository
2. Open the project folder in VS Code
3. Create and activate a virtual environment
4. Install dependencies using requirements.txt
5. Run the Streamlit application

### Commands

Install dependencies

pip install -r requirements.txt

Run the app

streamlit run src/app.py

## Usage

- Use the sidebar to navigate between Add Student and View Students
- Fill in student details and save
- View all stored students in table format

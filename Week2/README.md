# Week 2: Data Handling and Visualization

## Assignment Overview

This project focuses on performing Exploratory Data Analysis on the Titanic dataset.  
The objective is to understand the dataset, clean missing values, and generate meaningful visualizations to identify patterns related to passenger survival.

---

## Dataset Description

The Titanic dataset contains information about passengers such as:

- Survival status
- Passenger class
- Gender
- Age
- Fare
- Embarkation point
- Family relations onboard

The goal of this analysis is to explore how these features relate to survival outcomes.

---

## Tasks Performed

1. Data loading using seaborn
2. Dataset inspection using head, info, and describe
3. Handling missing values
4. Dropping unnecessary columns
5. Generating visualizations:
   - Survival count
   - Survival by gender
   - Survival by passenger class
   - Age distribution
   - Correlation heatmap
6. Writing key observations and insights

---

## Tools and Libraries Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Google Colab

---

## Key Insights

- Female passengers had significantly higher survival rates.
- First class passengers survived more frequently than lower classes.
- Fare and passenger class showed strong influence on survival probability.
- Age had moderate influence compared to class and gender.

---

## How to Run

1. Open the notebook in Google Colab.
2. Run all cells sequentially.
3. All required libraries are included in Colab by default.
4. No external dataset upload is required since the dataset is loaded directly using seaborn.
